# How should future value be measured?

## Future Value Definition


Future Value represents the long-term professional value generated by a player after leaving college.


The score should capture:

- NBA longevity

- NBA impact

- Market value

- Career success


Potential metrics:

- Seasons played

- Career Win Shares
  
- VORP
  
- Total minutes played
  
- Career earnings
  
- All-Star appearances
  
 
The final Future Value Score will normalize these variables into a 0-100 scale.
